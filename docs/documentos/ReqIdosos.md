## Requisitos para o público idoso, Interação Humano Computador

| Área                  | Recursos/recomendações encontradas                                                    |
| --------------------- | ------------------------------------------------------------------------------------- |
| **Interface visual**  | fontes maiores, layout simples, elementos visualmente claros                          |
| **Controles**         | botões e áreas de toque maiores, maior distância entre elementos clicáveis            |
| **Navegação**         | navegação simples e consistente                                                       |
| **Carga cognitiva**   | reduzir quantidade de informação apresentada simultaneamente                          |
| **Interação**         | tornar entradas e respostas do sistema mais claras, interfaces tolerantes a erros     |
| **Feedback**          | fornecer retorno claro após ações do usuário                                          |
| **Ícones**            | utilizar ícones compreensíveis e acompanhados de informação textual quando necessário |
| **Ajuda/treinamento** | disponibilizar orientação e auxílio ao usuário                                        |
| **Entrada de dados**  | reduzir complexidade da interação e facilitar a entrada (interação por voz)           |
| **Simplificação**     | evitar funcionalidades e passos desnecessários                                        |

Referências: Gomez-Hernandez et al. (2023) — “Design Guidelines of Mobile Apps for Older Adults: Systematic Review and Thematic Analysis” e  Amouzadeh et al. (2025) — “Optimizing mobile app design for older adults: systematic review of age-friendly design”.
